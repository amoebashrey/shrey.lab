Patterns & structures

Higher-level UI patterns — accordion, table, empty state, skeleton, kbd.

Accordion (FAQ)

Can I use this kit in any project?
Yes. Drop the shrey-lab/ folder into any project, import tokens.css, and you're set. Tailwind preset works for Tailwind projects; raw CSS works everywhere.
Do I have to use all of it?
No. The minimum is BRAND.md + tokens.css. Components and pages are optional.
What if I want to change a color?
Change it in tokens.css once, every project that uses the kit updates. That's the whole point.
